# Release fonts

The browser and print builds use the same three upright variable TrueType files. Each file is distributed with its original SIL Open Font License. The files come from the [pinned Google Fonts collection](https://github.com/google/fonts/tree/5bd87dfc525c8a0d1d8529d3684716e00c3fc59a/ofl).

| Source directory | Local filename | Use |
|---|---|---|
| ebgaramond | EBGaramond.ttf | Titles and headings |
| atkinsonhyperlegiblenext | AtkinsonHyperlegibleNext.ttf | Explanatory text, categories and controls |
| jetbrainsmono | JetBrainsMono.ttf | Quantities, numeric axes and codes |
